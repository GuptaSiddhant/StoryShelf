Fixed: one focus ring, one disabled look and an accessible step marker across the UI

Menus and disclosures show the same ring as other controls, and focus no longer changes a control's corners. Disabled buttons, link buttons, fields, selects and check boxes share one look, `Table` gets an `empty` prop, the rail's help menu keeps its icon, the profile and get-started markers read in both themes, and the capture settings no longer offer the primary browser as an extra.
