Breaking: server terraform generators are replaced by versioned Terraform modules

`storyshelf server terraform-aws`, `terraform-gcp` and `terraform-azure` are removed, and `storyshelf server init` no longer offers `aws`, `azure` or `gcp` deploy targets, writes `terraform/` or adds `infra:*` scripts. Run `storyshelf server init --cloud aws|gcp|azure` instead: it writes a `main.tf` that uses the cloud's module from `deploy/terraform/<cloud>` at the CLI's own version, and a `terraform.tfvars` from its prompts. A stack generated by an older CLI moves over with the migration guide on the website.
