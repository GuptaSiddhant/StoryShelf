Breaking: server terraform generators are replaced by versioned Terraform modules

`storyshelf server terraform-aws`, `terraform-gcp` and `terraform-azure` are removed, and `storyshelf server init` no longer offers `aws`, `azure` or `gcp` deploy targets, writes `terraform/` or adds `infra:*` scripts. Run `storyshelf server init --cloud aws|gcp|azure` instead: it writes a `main.tf` that uses the cloud's module from `deploy/terraform/<cloud>` at the CLI's own version, a `terraform.tfvars` from its prompts, and a `.gitignore` for the state and plan, which hold secrets. A stack generated by an older CLI moves over with the migration guide on the website.

The modules keep the generators' optional git connection inputs (`github_app_id`, `github_api_url`, `gitlab_host`, `gitlab_token_expires` and a secret reference for the App private key and the GitLab token, never a value), and a half-set connection fails the plan.
