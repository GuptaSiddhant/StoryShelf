`@storyshelf/ai` implements the `Ai` surface that `ShelfOptions.ai` accepts. It owns the `ai` core and `@ai-sdk/otel` (pinned exactly) and never sees provider keys: you install a provider package and pass configured models in. See the [AI insights guide](/guides/ai-insights/) and [ADR 0026](https://github.com/GuptaSiddhant/StoryShelf/blob/main/docs/adr/0026-ai-insights-engine.md).

## Usage

```ts
import { createAi } from "@storyshelf/ai";

const ai = createAi({
  profiles: { default: { defaultModel: yourModel } },
  budget: { dailyTokens: 2_000_000 },
});
```

One export, `createAi`, plus the option types. Everything else is internal.
