import { PackageManagers } from "starlight-package-managers";

`@storyshelf/db-mysql` connects StoryShelf to MySQL or MariaDB through `mysql2` and Drizzle ORM. It implements the same `DatabaseAdapter` contract as [SQLite](../db-sqlite/) and [Postgres](../db-postgres/), so the rest of the application does not change when you switch databases.

## When to use it

Choose MySQL or MariaDB when that is what your team already runs or your platform provides. Pair it with [local storage](../storage-local/) for single-node deployments, or [S3-compatible storage](../storage-s3/) when instances do not share a filesystem.
