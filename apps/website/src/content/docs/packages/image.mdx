import { PackageManagers } from "starlight-package-managers";

`@storyshelf/image` is StoryShelf's image engine: it compares a baseline and a current screenshot with [pixelmatch](https://github.com/mapbox/pixelmatch), renders the diff overlay, and downscales screenshots into thumbnails for AI insights, all on a pool of worker threads. `@storyshelf/core` depends on it and re-exports it as `@storyshelf/core/diff`, so most setups never install or import it directly.

It is a **leaf package**: it imports nothing else from StoryShelf, and a test keeps it that way.
