import { PackageManagers } from "starlight-package-managers";

`@storyshelf/notify-chat` sends formatted build and admin alerts to chat over Slack and Microsoft Teams incoming webhooks, plus a log provider for tests and local development. It has no runtime dependencies: every send goes through `@storyshelf/core/utils` (`httpText`), which adds a timeout and retries with `Retry-After`.
