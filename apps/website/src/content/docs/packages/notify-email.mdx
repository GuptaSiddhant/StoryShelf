import { PackageManagers } from "starlight-package-managers";

`@storyshelf/notify-email` is the email transport for StoryShelf. One sender serves notification channels and, optionally, authentication mail such as invites and password resets. It is the only package that owns `nodemailer`.

## Install

<PackageManagers pkg="@storyshelf/notify-email" />

The SMTP preset needs the optional `nodemailer` peer; the log and HTTP presets do not:

<PackageManagers pkg="nodemailer" />

- [npm package](https://www.npmjs.com/package/@storyshelf/notify-email) — install tarballs and version history.
- [Source on GitHub](https://github.com/GuptaSiddhant/StoryShelf/tree/main/packages/notify-email) — package directory on `main`.
