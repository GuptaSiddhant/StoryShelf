`@storyshelf/storage-azure` stores StoryShelf blobs in an **Azure Blob Storage** container. It persists the same artifacts as the other storage adapters — captured screenshots, diff overlays, and uploaded Storybook archives.

## When to use it

Choose Azure Blob Storage for Azure deploys — Container Apps, AKS, or Functions — especially paired with [db-postgres](../db-postgres/). It is a drop-in replacement for [local storage](../storage-local/) and [S3 storage](../storage-s3/); for Google Cloud see [storage-gcs](../storage-gcs/).
