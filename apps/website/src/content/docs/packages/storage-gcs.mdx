`@storyshelf/storage-gcs` stores StoryShelf blobs in a **Google Cloud Storage (GCS)** bucket — captured screenshots, diff overlays, and uploaded Storybook archives.

## When to use it

Use GCS for GCP deploys — Cloud Run, GKE, or Cloud Functions — especially paired with [db-postgres](../db-postgres/). It is a drop-in replacement for [local storage](../storage-local/), [S3](../storage-s3/), and [Azure Blob](../storage-azure/).
