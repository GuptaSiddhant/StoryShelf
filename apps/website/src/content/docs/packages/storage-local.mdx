`@storyshelf/storage-local` is **deprecated**. Local filesystem storage is built into core, and the factory and its options are unchanged. This package re-exports it for one minor release (ADR 0049), then is no longer published.

## Migrate

```ts
// before
import { createLocalStorage } from "@storyshelf/storage-local";
// after
import { createLocalStorage } from "@storyshelf/core/storage/local";
```

Remove `@storyshelf/storage-local` from your `package.json` and keep `@storyshelf/core`.

## `createLocalStorage(dataDir: string): StorageAdapter`

Stores all blobs under the resolved `dataDir`, creating directories as needed. A path that escapes the data directory throws.

## When to use it

Use local storage with [SQLite](../db-sqlite/) for a simple single-node deployment. For cloud or multi-node deployments where instances need shared objects, switch to [S3 storage](../storage-s3/) without changing the core router.
