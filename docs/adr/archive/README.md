# Archived ADRs

These are the pre-consolidation ADRs (0001 to 0036), frozen under their original numbers and file
names. They are historical records: **do not edit them**. Current decisions live in
[`../README.md`](../README.md).

Refer to one of these as `archived ADR NNNN` (or link the file here); a bare `ADR NNNN` means a
current ADR.
